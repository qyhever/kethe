# 成员功能发布与验证

发布顺序：执行 `sql/2026-10-20-members.sql` → 部署后端 → 在后端目录执行 `pnpm backfill:defaults` → 发布 H5。全新数据库使用已更新的 `sql/init.sql`，无需再次执行升级脚本。

回填按用户和 `systemKey` 补齐六个成员，会读取软删除记录，不覆盖名称、图标或删除状态。注册与后台创建用户沿用同一默认初始化事务。

接口示例见 `rest/index.http`。流水创建省略 `memberId` 等价于 `null`；修改省略时保留，传 `null` 清空。转账只接受空成员。已删除成员可以在原流水上保留，不能新建关联或从其他成员改回。

在后端目录运行：

```powershell
pnpm build
node scripts/verify-members.cjs
pnpm exec jest member default-user-data ledger.service --runInBand
pnpm test:cov -- --runInBand
```

`verify-members.cjs` 使用 `.env` 数据库连接创建随机命名的 `kethe_members_verify_*` 临时数据库，完成后清理；数据库用户需有创建和删除临时库权限。脚本验证全新建库、存量升级、旧流水空关联、默认初始化幂等、成员切换与清空、跨年汇总、累计支出、用户隔离、软删除及历史回显。

H5 验收链路：我的 → 成员设置 → 新增 / 左滑编辑与删除 → 点击成员查看全部支出 → 筛选成员 → 编辑记账 → 返回确认筛选、来源与滚动位置保留。记一笔默认“无”，收支切换保留成员，切换转账清空成员；成员请求失败时可重试且不丢失已有流水关联。
